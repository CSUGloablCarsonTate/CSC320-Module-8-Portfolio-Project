START

Create Automobile Class

    Store private attributes:
        make, model, color, year, mileage

    Default Constructor:
        Set vehicle information to empty values

    Parameterized Constructor:
        Store the vehicle information provided

    setVehicleDetails:
        Check that vehicle information is valid
        Store the vehicle information

    clearVehicle:
        Clear the vehicle information

    addVehicle:
        Check if the vehicle record is empty
        Add the new vehicle information
        Return success or failure message

    removeVehicle:
        Check if vehicle information exists
        Clear the vehicle information
        Return success or failure message

    updateVehicle:
        Check if vehicle information exists
        Update the vehicle information
        Return success or failure message

    listVehicle:
        Return vehicle information as a String array

    Use TRY and CATCH to handle errors


Create AutomobileInventory Class

    Set maximum inventory to 6 vehicles

    Create an ArrayList to store automobiles

    Add the five starting vehicles:
        Toyota Corolla
        Toyota Tacoma
        Honda Pilot
        Subaru Impreza
        Ford Escape

    Display the current vehicle inventory

    WHILE the program is running

        Display Main Menu:
            1. View all vehicles
            2. Add a vehicle
            3. Update a vehicle
            4. Remove a vehicle
            5. Print inventory to file
            6. Exit

        Ask the user to enter a selection

        IF selection is 1
            Display all vehicles in the inventory

        ELSE IF selection is 2
            Check if inventory has fewer than 6 vehicles
            Ask user for new vehicle information
            Add vehicle to inventory
            Display the result and new vehicle information

        ELSE IF selection is 3
            Ask user to select a vehicle
            Ask for updated vehicle information
            Update the selected vehicle
            Display the result and updated information

        ELSE IF selection is 4
            Ask user to select a vehicle
            Ask user to confirm removal
            IF user selects Yes
                Remove the selected vehicle
                Display the result and remaining inventory
            ELSE
                Display vehicle was not removed
            END IF

        ELSE IF selection is 5
            Ask user to print inventory to file (Yes/No)
            IF user selects Yes
                Save all vehicle information to C:\Temp\Autos.txt
                Display success or failure message
            ELSE
                Display that the file will not be printed
            END IF

        ELSE IF selection is 6
            Display exit message
            Stop the program

        END IF

    END WHILE

    Use loops to display vehicle information
    Check user input and ask again if invalid
    Use TRY and CATCH to handle errors

END
